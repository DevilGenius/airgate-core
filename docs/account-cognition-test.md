# 账号降智标记

需要同时更新 Core 和 OpenAI 插件。OpenAI 插件配置新增：

- `cognition_test_enabled`：默认关闭。
- `cognition_test_prompt`：开启检测后账号测试发送的提示词。
- `cognition_test_regexp`：Go RE2 正则；对拼接后的回复正文匹配，不包含推理文本和协议字段。需要全文匹配时使用 `^…$`，跨行可使用 `(?s)`。

开启后，测试成功且正文匹配时写入 `extra.cognition_degraded=false`；不匹配、空回复未匹配或上游测试失败时写入 `true`。凭证列表状态列的主状态行显示检测标签：正常为黑色系“正常”，降智为紫色“降智”，未检测不显示。此标记独立于调度器的临时 `degraded` 状态，不影响选路。

单个及批量“清除标记”同时删除检测属性，恢复未检测状态；不会将已检测降智改写成正常，也不会删除其他账号扩展属性。

关闭时发送原有 `hi`，不修改该属性。旧插件未提供策略接口时仍走普通测试。未检测的账号没有该属性。配置非法时拒绝检测且不修改属性。用户取消导致上下文失效时不会强行写入结果。

检测使用有界响应副本（4 MiB），不改变转发给测试弹窗的数据；超限按检测未通过处理。持久化通过原子 JSON 字段更新保留其他 `extra` 内容。单个账号测试完成及批量测试弹窗关闭后刷新列表。
